## 🎯 Course Overview

This repository contains practical work focused on the fundamentals of **data preparation, analysis, and visualization**.

The assignments demonstrate how Python can be used to:

- 🧹 Prepare and organize datasets
- 🔎 Explore and analyze data
- 📈 Create meaningful visualizations
- 🐍 Apply Python data-science libraries to real-world datasets
